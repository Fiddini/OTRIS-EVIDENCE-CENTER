# OTRIS-EVIDENCE-CENTER
Evidence Center untuk mendokumentasikan fakta, dokumen, transaksi, kronologi, komunikasi, dan bukti terkait perkara yang melibatkan PT Hematech Nusantara dan OTRIS, termasuk proses di Kejati Riau, Polda Riau, serta perkara terkait Dumai.
