# OTRIS EVIDENCE CENTER

**Pusat dokumentasi fakta, dokumen, transaksi, kronologi, komunikasi, dan bukti terkait PT Hematech Nusantara dan OTRIS.**

> **Kami hanya mencatat. Kami tidak menuduh.**

Repository ini dibuat untuk menyimpan dan menyajikan dokumentasi secara terstruktur terkait berbagai proses dan peristiwa yang melibatkan PT Hematech Nusantara dan OTRIS, termasuk perkara yang berkaitan dengan Kejati Riau, Polda Riau, dan Dumai.

## Prinsip Evidence Center

Setiap informasi dibedakan berdasarkan kekuatan sumbernya:

- **D — Documented**: didukung dokumen.
- **V — Visual / Communication**: didukung foto, screenshot, scan, atau komunikasi.
- **FS — First-hand Statement**: keterangan pengalaman langsung sumber.
- **OPEN**: masih memerlukan verifikasi atau bukti tambahan.

Repository ini **bukan media untuk membuat tuduhan, menentukan kesalahan seseorang, atau mengambil kesimpulan hukum**.

Dokumen, komunikasi, dan kronologi disajikan sesuai sumber yang tersedia. Jika kemudian ditemukan bukti yang lebih kuat atau terdapat kekeliruan, koreksi dilakukan tanpa menghapus riwayat versi sebelumnya.

## Batas Publikasi

Repository publik ini hanya memuat material yang telah dipilih untuk konsumsi publik.

Catatan pemeriksaan pribadi, data sensitif, identitas yang tidak perlu dipublikasikan, dokumen internal, serta materi yang masih berstatus FS atau OPEN dapat disimpan terpisah dan tidak otomatis dipublikasikan di repository ini.

## Prinsip Utama

**Fakta dipisahkan dari interpretasi.  
Dokumen dipisahkan dari ingatan.  
Kronologi dicatat tanpa menuduh.  
Koreksi tidak menghapus sejarah.**
