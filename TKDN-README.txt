# TKDN - Tempat file TKDN

File TKDN yang piak baru masukkan via dashboard drag & drop:

1. Buka dashboard/index.html
2. Klik Download pada file TKDN
3. Simpan file asli TKDN.pdf ke folder ini: A-Dokumen-Resmi/TKDN.pdf
4. Push ke GitHub

Jika TKDN sudah ada file aslinya, ganti file ini dengan file asli.
