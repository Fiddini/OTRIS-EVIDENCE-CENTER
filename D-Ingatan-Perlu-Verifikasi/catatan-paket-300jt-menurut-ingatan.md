# Catatan Paket Pembanding - Menurut Ingatan Saya

Pada tahun yang sama, menurut ingatan saya, terdapat paket pengadaan lain dengan nilai keseluruhan sekitar Rp20 miliar, dengan harga sekitar Rp300 juta per unit, yang menurut ingatan saya merupakan IFP dan tidak sama dengan paket 3-in-1 yang saya kerjakan.

Saya sengaja menulis "menurut ingatan saya", karena saat klarifikasi ini dibuat saya belum mencocokkan kembali angka dan spesifikasi paket tersebut dengan dokumen resmi.

Karena itu saya tidak menyatakan bahwa angka Rp300 juta maupun Rp20 miliar tersebut merupakan fakta final.

Saya justru mempersilakan dan memohon agar data tersebut diperiksa melalui e-Katalog LKPP, kontrak, HPS, spesifikasi teknis, BAST, dan dokumen resmi pengadaan terkait.
